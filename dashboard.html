Save data to GitHub

Attendance, tasks and notes are stored in data/attendance.json, data/tasks.json and data/notes.json in the repository. To save changes there, paste a GitHub token with write access to the repo. It is stored only in this browser.

Without a token, anything you submit is saved only in this browser.

Create one at GitHub → Settings → Developer settings → Fine-grained tokens, limited to this repository with Contents: Read and write.
